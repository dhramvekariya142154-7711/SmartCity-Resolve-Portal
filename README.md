## 🚀 Key Features

1. **📊 Real-Time Dynamic Dashboard**
   - KPI metric cards (Total Filed, In Progress, Resolved, SLA Avg).
   - Quick activity feed and category breakdown overview.

2. **🤖 AI-Powered Complaint Filing ('CivicAssist AI')**
   - Natural Language Analyzer auto-detects complaint category and urgency levels (e.g., Water Leak vs Routine Road Repair).
   - Dynamic map pin location selector with auto-geocoding simulation.
   - File attachment dropzone with image previews.

3. **🔍 Interactive Issue Tracker & Filtering**
   - Multi-parameter search and status filters (All, Pending, In Progress, Resolved).
   - Interactive modal popup with timeline tracking, assigned department officer, and citizen comments feed.
   - Public upvote mechanic for prioritization.

4. **💬 CivicAssist Chatbot Companion**
   - Floating and tab-integrated conversational AI assistant.
   - Smart prompt quick buttons to draft complaints, check status, or get emergency helpline numbers.

5. **📈 Admin & Analytics Panel**
   - Dynamic interactive charts using **Chart.js** (Category Doughnut & SLA Bar Chart).
   - Department efficiency scorecards and status control toggles.

6. **🌗 Dark/Light Mode & Non-Blocking Toasts**
   - Full dark mode toggle saved across browser sessions.
   - Real-time toast alerts for actions.

## 🌐 Deploying to GitHub Pages

1. Go to your GitHub repository settings: `Settings > Pages`.
2. Under **Build and deployment > Source**, select `Deploy from a branch`.
3. Choose `main` (or `master`) branch and `/ (root)` folder.
4. Click **Save**. Within 1–2 minutes, your web application will be live at:
   `https://<your-username>.github.io/smartcity-resolve/`
